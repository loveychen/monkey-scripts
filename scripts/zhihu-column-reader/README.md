# 知乎专栏 · 沉浸阅读

保留知乎专栏的文章标题、作者和正文，隐藏导航、侧栏与推荐，提供低打扰的阅读设置。

## 安装

1. 安装 Tampermonkey。Chrome 如有“允许用户脚本”选项，请确认已经开启；具体要求见 [Tampermonkey 官方说明](https://www.tampermonkey.net/faq.php?locale=en&q=Q209)。
2. 打开 [Greasy Fork 发布页](https://greasyfork.org/zh-CN/scripts/603576)，点击安装。
3. 刷新知乎专栏文章。新安装默认自动进入，旧版保存的设置会继续保留。不要同时启用两份同名脚本。

适用范围为 `https://zhuanlan.zhihu.com/p/*`，不作用于首页和问答页面。

## 使用

右上角的阅读设置图标支持悬停或键盘聚焦展开，点击可以固定展开。退出后，同一文章不会立即自动重新进入。

- **主题**：跟随系统、浅色、纸色、深色；手动选择不受系统外观变化覆盖。
- **阅读宽度**：自适应、720px、960px、铺满。旧版固定宽度偏好会保留，想利用更多屏幕空间时可重新选择。
- **排版**：16–28px 字号、衬线字体；调整时尽量保持当前阅读段落。
- **目录**：默认隐藏，点击“目录”展开，支持章节跳转和当前章节高亮。
- **图片**：点击正文图片打开查看器，再点击切换适应窗口与原尺寸；Esc、关闭按钮或背景可以关闭。深色模式下可主动开启正文图片柔化，预览仍保留原色。
- **续读**：本地记录当前段落；重新打开时尽量恢复。用户先行滚动和链接锚点优先，点击“从头”可清除该文断点。
- **评论**：按需显示原站已加载的评论，并可返回正文。尚未加载时使用原页入口。
- **进度与全屏**：进度按正文计算；全屏需要用户主动操作，浏览器拒绝时给出提示。

| 快捷键 | 功能 |
| --- | --- |
| macOS ⌥R / 其他系统 Alt+R | 进入或退出阅读 |
| Esc | 依次关闭图片、目录或评论，再退出阅读；浏览器可能先退出全屏 |
| T | 循环切换主题 |
| W | 循环切换宽度 |
| ＋ / − | 调节字号 |
| F | 切换浏览器全屏 |

Tampermonkey 菜单提供自动进入开关、进度显示开关、清除本地阅读进度和版本入口。

## 数据与兼容性

阅读偏好和断点保存在脚本管理器本地。断点包含文章地址、标题、段落 ID 或短文本、段内位置及时间，最多保留 100 篇；90 天前的断点不再恢复，并在下次写入时清理。清除阅读进度不会删除主题等偏好。

脚本不上传阅读内容，不提供云同步，不请求额外文章接口，不绕过登录、付费或访问限制。原站图片、公式与评论的加载仍依赖知乎页面；检测到必要登录或验证对话框时恢复原页。正文结构变化可能影响识别；异常时可以退出，必要时禁用脚本并刷新。

## 构建与发布

在仓库根目录执行：

```bash
npm run build:zhihu
npm run check:zhihu
```

也可在当前目录运行 `node build-userscript.mjs`。修改 `src/content.js` 与 `src/reader.css` 后重新构建；版本统一在 `release.json` 中修改。完整脚本、元信息、源码与版本配置一起提交。

Greasy Fork 同步 [zhihu-column-reader.user.js](zhihu-column-reader.user.js)，不直接同步源码。现有 `@namespace` 和 Greasy Fork 更新地址保持不变。[仓库发布说明](../../docs/publishing.md)列出了准确同步地址。

本次迁移保留 1.3.0 的源码和生成文件，未增加阅读功能。构建与语法检查不等于真实知乎和 Tampermonkey 安装验收。
