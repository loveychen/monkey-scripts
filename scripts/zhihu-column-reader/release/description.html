知乎专栏 · 沉浸阅读

打开知乎专栏，专注阅读。自动隐藏导航、侧栏、推荐和评论，保留标题、作者、正文、图片、代码与表格。脚本不提供额外账号服务，不上传阅读内容。

安装与更新

  1. 在 Chrome 中安装 Tampermonkey，右键扩展图标，进入“管理扩展程序”，开启“允许用户脚本”。
  2. 点击本页的“安装此脚本”。已经安装时，可点击页面提供的更新或重新安装按钮。不要同时启用两份。
  3. 刷新知乎专栏文章。新安装默认自动进入；如果旧设置关闭了自动进入，请在 Tampermonkey 菜单中开启一次。

固定安装与更新入口：本脚本发布页。脚本仅适用于 https://zhuanlan.zhihu.com/p/*，不处理知乎首页和问答页面。

日常使用

右上角仅保留一个小巧的阅读设置图标。悬停或键盘聚焦可临时展开，点击可固定展开，再点一次收起。点击“退出”或按 Esc 恢复原页面；同一文章内不会立刻再次自动进入。

  • 阅读宽度：自适应随窗口扩展；720px 和 960px 为固定版心；“铺满”尽量利用屏幕空间。旧版固定宽度会保留，想用更多屏幕空间时请选择“自适应”或“铺满”。
  • 阅读主题：跟随系统、浅色、纸色、深色。选择跟随系统后随 macOS 深浅色变化；手动主题不受系统变化覆盖。旧主题设置会保留，可重新选择跟随系统。
  • 字号与字体：A−／A+ 在 16–28px 之间调整字号，也可切换衬线字体。
  • 断点续读：正常阅读时记住段落，重新打开文章后尽量恢复。用户先滚动、链接带章节锚点时优先尊重当前操作。点击“从头”重新开始。
  • 文章目录：点击“目录”按需展开章节列表，点击标题跳转，当前章节会高亮。没有标题的文章不生成章节目录。
  • 图片放大：点击正文图片进入独立查看器，点击预览切换适应窗口和原尺寸；Esc、关闭按钮或点击背景退出。不会隐藏正文原图，放大时保留原色。
  • 柔化图片：默认关闭。勾选后仅在深色模式下降低正文图片亮度，放大预览不受影响。
  • 评论：点击“评论”显示原站已加载的评论，继续使用原输入和按钮；点击“返回正文”回到刚才的段落。尚未加载时会提示使用原页入口。
  • 正文进度：顶部进度条按正文范围计算，不包含页头、评论及页底留白。1.4.0 起，展开阅读设置还会显示“已读 XX%”，随滚动更新；关闭阅读进度时同时隐藏。正常读到正文末尾后会清理该文断点。
  • 浏览器全屏：点击全屏按钮或按 F，由用户主动触发。浏览器拒绝时会显示简短提示，不会自动修改浏览器设置。

引用与摘录（1.5.0）

展开阅读设置，点击“引用”预览和编辑标题、署名、日期、来源链接与引用键。支持 BibLaTeX 的 @online 和传统 BibTeX 的 @misc，可复制或下载 .bib。机构或账号署名默认按原样保留；缺失作者或发布日期时留空，编辑日期不会代替发布日期。最终参考文献格式由所用论文模板决定，传统格式的链接显示需要 url 或 hyperref 支持。

先选择正文文字再打开引用，即可复制保留换行并附带署名、标题、链接与日期的 Markdown 摘录；也可在摘录框中粘贴原文。面板默认隐藏，选中文字时不弹窗。复制被拒绝时会选中内容供手动复制。引用修改和摘录只用于当前面板，不写入存储，不新增权限或额外联网。

快捷键

  • macOS 为 ⌥R（Option＋R），其他系统为 Alt＋R：进入或退出阅读。
  • Esc：优先关闭图片查看器，其次引用、目录、评论，最后退出阅读。浏览器可能先用 Esc 退出全屏。
  • T：按跟随系统、浅色、纸色、深色循环切换主题。
  • W：按自适应、720px、960px、铺满循环切换宽度。
  • ＋／−：调字号；F：切换浏览器全屏。输入文字时不会接管 T、W、F 和字号快捷键。

本地记录

阅读偏好和断点只保存在脚本管理器本地。断点包含文章地址、标题、段落 ID／短文本、段内偏移和时间，最多保留 100 篇；90 天前的断点不再恢复，并在下次写入时清理。Tampermonkey 菜单提供“清除本地阅读进度”，不会删除主题等偏好。不提供跨设备云同步。

常见问题与边界

  • 没有入口或没有自动进入：确认 Chrome 的“允许用户脚本”、Tampermonkey 和本脚本均已开启，再刷新文章。脚本显示“已启用”并不代表浏览器已允许它执行。
  • 登录或验证：检测到必要的可见对话框时会恢复原页面，完成后可手动返回阅读。脚本不绕过登录、付费或网站访问限制。
  • 图片一闪即逝：请确认已更新到 1.3.0 或以上并刷新文章；旧版笼统隐藏正文外浮层可能影响原站灯箱。
  • 续读没有恢复：文章内容变化、段落未匹配或用户已经操作时，会保留当前阅读位置。不要将断点记录当作永久收藏。
  • 兼容性：更早启动仍需等待正文和设置可用，不能保证绝对无闪烁；原站的图片、公式和评论加载取决于原页面。排版异常时可先退出，必要时禁用脚本并刷新。
