# 1.4.0 验证记录

日期：2026-11-03。基线：仓库中的 1.3.0；候选：阅读设置中的正文百分比。

## 本地验证

- 构建、生成文件一致性和 JavaScript 语法检查。
- Chrome 运行完整生成脚本；正文为本地合成文章，GM 存储和菜单由测试页适配。
- 基线没有百分比文字；新版工具栏默认折叠时不显示，展开后显示“已读 0%”。
- 通过浏览器滚动后显示“已读 43%”，与原进度条的值一致。
- 原有进度开关同时隐藏和恢复进度条与百分比。
- “从头”回到 0%；正文末尾滚动完成后为 100%；一屏可见的短文为 100%。

上述检查覆盖本轮新增行为，不代替真实知乎页面及 Tampermonkey 安装验收。快速大幅滚动后应在滚动事件处理完成后读取结果，不能将紧接输入的瞬时快照当作最终状态。

## 同步验收

1.4.0 的首次功能提交没有手动触发 Greasy Fork 同步。后续用户另行授权配置 Webhook，配置及实测结果见 [同步记录](../../../docs/webhook-sync-status.md)。

用户可检查 Greasy Fork 是否自动出现 1.4.0，再让 Tampermonkey 检查更新并刷新文章，展开阅读设置确认“已读 XX%”出现且随滚动变化。GitHub 提交、Greasy Fork 同步、浏览器安装分别判断；本地验证不能证明同步成功。
