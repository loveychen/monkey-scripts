# 知乎阅读脚本 1.5.0：引用与摘录

## 当前结论

用户已确认实现引用预览、BibTeX 导出、摘录带出处，保持低打扰，完成后升级并推送。基线为 main 的 1.4.0，已有 Webhook 同步到 Greasy Fork 条目 603576。

实现选择：阅读设置增加“引用”，打开默认隐藏的非模态面板。提供可编辑元信息、BibLaTeX @online / 传统 BibTeX @misc、复制与下载 .bib、选区摘录和出处复制。不会在选中正文时自动弹窗；数据不持久化，不新增联网或 GM 权限。

元信息优先来自当前正文及匹配当前文章的结构化信息。发布时间与编辑时间分开；日期和作者缺失时留空并提示，机构/账号署名可按字面保留。引用键默认以文章 ID 生成；标题和特殊字符正确转义。复制失败时提供手动选择复制的内容，不能谎报成功。退出、Esc 和 SPA 换文清理面板，避免旧文资料串入新文。

## 验证状态

核心和面板已实现。Node 引用格式测试 9 项通过；内置浏览器已验证默认隐藏、字段编辑、两种格式、真实剪贴板复制、真实 .bib 下载且文件内容与预览一致、正文/非正文选区、缺作者/发布日期、异文结构化信息排除、SPA 换文清理、剪贴板拒绝与迟到反馈。

只读交互审查指出关闭面板时原引用按钮可能已隐藏，导致焦点丢失。已在浏览器复现并修复：恢复到可见控件，否则回到阅读设置按钮；键盘 Esc 回归通过。

真实知乎页在内置浏览器可访问：署名链接为 `.Post-Author a[href*="/org/"]`，日期是 article 内 `meta[itemprop=datePublished/dateModified]`，可见日期仅显示编辑日期。实现已覆盖该结构，带时区的元信息日期按知乎的上海日期转换，显示的明确日期优先。真实已安装 1.5.0 脚本尚未验证；Chrome 工具连接当前不可用。
